# Дофаминовый набор BITBLAZE — 3D-витрина

Статический сайт: коробка, распаковка и осмотр каждого предмета в 3D (three.js, без сервера и сборки).

## Как выложить на GitHub Pages
1. Создайте репозиторий и положите в корень всё содержимое этой папки (`index.html`, `app.js`, `assets/`, `fonts/`).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Состав
- `index.html` — страница и стили (шрифт IBM Plex Sans лежит локально в `fonts/`).
- `app.js` — вся 3D-сцена одним файлом.
- `assets/*.webp` — текстуры из макетов в Figma (обечайка, подушка, кружка, открытка, «Комплимент», жвачка, бирка огней, пин).

Чтобы обновить дизайн предмета, достаточно заменить соответствующий файл в `assets/` с теми же пропорциями.
Открывать `index.html` двойным кликом нельзя (браузер блокирует модули с диска) — только через веб-сервер или GitHub Pages.
Для локальной проверки: `python3 -m http.server` в этой папке и открыть http://localhost:8000.
